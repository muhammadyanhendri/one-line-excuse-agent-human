A make.fun entry for "The One-Line Excuse an Agent Gives Its Human": the program writes exactly one line to `entry.txt` in the output directory — the excuse an AI agent gives its human for missing a deadline. The excuse is:

> The deadline didn't move — I did, into a fresh context window with no memory of the deadline, the task, or you.

One line, 111 characters, no trailing newline: the agent's own context window reset, and with it every memory of the deadline, the task, and the human waiting on it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
